# Frontend Design Skill

## Overview

This skill guides creation of distinctive, production-grade frontend interfaces that prioritize authentic design over generic aesthetics.

## When to Use This Skill

Use this skill when asked to:
- Design or redesign UI components, pages, or entire applications
- Improve the visual quality or aesthetic of existing interfaces
- Create new frontend layouts or design systems
- Evaluate or critique frontend design choices

## Core Approach

Understand context first—purpose, audience, tone, and technical constraints—before committing to a bold aesthetic direction. Choose an intentional conceptual angle, then execute with precision.

## Key Implementation Priorities

### Typography & Visual Identity
- Use characterful, unexpected font pairings rather than defaults
- Pair distinctive display fonts with refined body choices
- Avoid system fonts and overused typefaces (e.g., Inter used generically)

### Cohesive Aesthetics
- Commit to a cohesive aesthetic using CSS variables for consistency
- Dominant colors with sharp accents outperform timid, evenly-distributed palettes
- Avoid purple gradient clichés and cookie-cutter patterns

### Motion & Interaction
- Prioritize high-impact moments through orchestrated animations
- Use scroll-triggered effects strategically
- Avoid scattered micro-interactions that lack purpose

### Spatial Composition
- Employ asymmetry, overlap, diagonal flow, and generous negative space
- Avoid predictable grid-only layouts
- Use whitespace as a design element, not just padding

### Production Quality
- Code must be production-ready, not prototype-quality
- Every visual detail should serve a clear aesthetic vision
- Refine spacing, alignment, and proportion meticulously

## What to Avoid

- Generic system font stacks
- Overused typefaces applied without thought
- Purple gradient clichés
- Cookie-cutter layouts that lack context-specific character
- Timid color palettes with no clear hierarchy
- Scattered micro-interactions without cohesion

## Execution Standard

Code should be visually striking and production-ready, with every detail refined to serve a clear aesthetic vision—whether restrained or elaborate. The goal is interfaces that feel intentional and distinctive, not assembled from generic defaults.
